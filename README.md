# La cinta · demo

Demo navegable de la propuesta para **Travelpro**: una cinta de equipajes 3D con las maletas del
catálogo real. Pasa el cursor por una maleta para ver precio, medidas, garantía y por qué es la
mejor; haz clic para elegirla. Cada millón de viajeros aparece la maleta dorada, que regala un viaje.

- Una sola página, sin build: three.js 0.160 por CDN y todo lo demás procedural.
- Precios y medidas: catálogo oficial de Travelpro Europa (21-nov-2026).
- Si el navegador no puede dibujar WebGL, la lista completa de maletas sigue visible debajo.
- Lenguaje visual tomado de la tienda oficial (hueso, marrón, tracking, radios 0).

Dossier completo (privado): `Ntizar/travelpro`.
